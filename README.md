## 📖 Introduction

Welcome to the **deciflow-frontend** project. This application helps you manage purchase requests with a smooth approval process. Built with modern web technologies, it ensures a user-friendly experience while allowing for thorough tracking of your requests. 

## ⚙️ Features

- **Multi-Level Approval Workflows**: Submit requests that require approval from multiple users.
- **User Authentication**: Secure login processes keep your data safe.
- **File Attachments**: Easily attach files to your purchase requests.
- **Approval Timeline Tracking**: View the entire history of your request approvals.
- **Comprehensive Testing**: Built with tools that ensure a stable experience (Playwright & Vitest).

## 🖥️ System Requirements

To run **deciflow-frontend**, ensure your computer meets these requirements:

- **Operating System**: Windows 10 or later, macOS 10.14 or later, or a recent Linux distribution.
- **RAM**: Minimum 4 GB of RAM is recommended.
- **Disk Space**: At least 200 MB of free disk space.

Make sure your computer is updated to the latest version for best performance.

## 📝 Usage Instructions

1. **Sign In**: If it is your first time, create an account with the sign-up option. Returning users must log in with their credentials.
2. **Create a Purchase Request**: Use the dashboard to create new purchase requests. Enter required information and attach relevant files.
3. **Submit for Approval**: After filling out the request, submit it for approval. You can track the approval status on the dashboard.

## 🔍 Troubleshooting

If you run into issues:

- **Not Launching**: Ensure your system meets the requirements.
- **Login Issues**: Check your username and password. Use the 'Forgot Password?' link to reset.
- **File Attachments Not Working**: Verify your files are of supported formats (PDF, DOCX, etc.).
